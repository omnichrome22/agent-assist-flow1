# Agent Assist · Flow 1 prototype

A clickable code prototype of **Flow 1: Cancel with Penalty** from the Agent-Assist_OneDesk Figma file.

**Live:** https://omnichrome22.github.io/agent-assist-flow1/

It's a single `index.html` with no build step or dependencies. Open it in a browser, or serve the folder.

## Using it

- The traveler's replies arrive on their own. Each of the agent's replies is pre-filled in the chat composer: edit it if you like, then click Send.
- Agent Assist actions work: Copy summary, Call property, One-click cancel, Close this case, and the feedback rating.
- The bar at the bottom has Back, Next, Restart and a hint toggle. The ← and → keys also step through the flow.
